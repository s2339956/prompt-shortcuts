# Prompt Shortcuts

This repository stores reusable prompt command documents and workflow rules.

## Structure

- `docs/workflows/`: command systems, shortcut rules, and workflow definitions.
- `prompts/image/cities/`: city-based image generation prompts.
- `prompts/storyboards/nine-grid/`: reusable 9-panel storyboard prompt templates.

## Key Files

- `docs/workflows/50-core-shortcuts.md`: the core shortcut command definitions table.
- `docs/workflows/50-core-shortcuts.zh-TW.md`: the Traditional Chinese source version.
- `docs/workflows/combo-workflow.md`: the combo workflow execution rules.
- `docs/workflows/combo-workflow.zh-TW.md`: the Traditional Chinese combo workflow version.
- `prompts/image/cities/beijing-tiny-planet.zh-TW.md`: Beijing tiny-planet travel prompt.
- `prompts/storyboards/nine-grid/9-panel-storyboard-templates.zh-TW.md`: 10 reusable 9-panel storyboard templates.

## Usage

These documents define a command-driven prompting style for writing, analysis, coding, planning, formatting, image prompt generation, and storyboard template tasks.
