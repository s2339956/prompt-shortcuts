# Prompt Shortcuts

This repository stores reusable prompt command documents and workflow rules.

## Contents

- `docs/50-core-shortcuts.md`: the core shortcut command definitions table.
- `docs/50-core-shortcuts.zh-TW.md`: the Traditional Chinese source version.
- `docs/combo-workflow.md`: the combo workflow execution rules.

## Usage

These documents define a command-driven prompting style for writing, analysis, coding, planning, and formatting tasks.
