# 50 個核心快捷指令定義表

## 核心快捷指令定義表

| 指令 | 核心功能 | 具體執行規範與輸出要求 |
| :--- | :--- | :--- |
| `/new` | 清空對話脈絡 | 忽略之前對話的所有背景與設定，完全開啟一個全新、乾淨的主題。 |
| `/nofluff` | 直接講重點 | 省略所有客套話、問候語與無意義的解釋，直接給出核心答案。 |
| `/tldr` | 太長不看 | 將長文、網頁或上傳的檔案，精煉濃縮成 3 個含金量最高的重點字句。 |
| `/table` | 強制轉為表格 | 拋棄段落論述，強迫將數據、對比或散亂的文字整理成 Markdown 表格輸出。 |
| `/action` | 產出行動清單 | 忽略背景論述，直接列出該專案或會議記錄後，後續具體要做的 Action Items。 |
| `/polish` | 文章文案潤飾 | 不改變原文意思，修正錯字、優化文法，提升整體的流暢度與專業商務感。 |
| `/summary` | 提供結構化摘要 | 將大量資訊分門別類，提供帶有清晰小標題、分段落的核心摘要。 |
| `/outline` | 生成結構大綱 | 將凌亂的想法或資料，自動整理成結構嚴謹的文章或簡報大綱。 |
| `/keywords` | 提取關鍵字/標籤 | 快速抓出文章中核心的關鍵字、主題標籤（Hashtags），適合 SEO 評估。 |
| `/rewrite` | 重寫（保持原意） | 當提供的文字讀起來很卡或不順暢時，請換一種更流暢、更自然的方式改寫。 |
| `/tone [風格]` | 切換特定語氣 | 例如接續 `/tone 幽默` 或 `/tone 嚴肅`，一鍵轉換回應的溫度與說話風格。 |
| `/reply` | 商務郵件自動延伸 | 根據提供的粗略想法（如：拒絕邀約），自動延伸出格式完整的商務 Email 草稿。 |
| `/pitch` | 電梯簡報（30秒短講） | 將複雜的專案或概念，濃縮成一段最精煉、最能在短時間內說服人的文案。 |
| `/pr` | 官方新聞稿格式 | 將內部公告、活動或新產品資訊，轉換為標準的公關新聞稿體裁。 |
| `/slang` | 社群流行語口吻 | 將死板文案轉換為適合 Thread、脆、IG 等社群網路的吸睛流暢風格。 |
| `/eli5` | 用 5 歲小孩能懂的白話 | 用最簡單的日常生活比喻、完全不帶專業術語的方式來解釋複雜概念。 |
| `/vs` | 橫向深度對比 | 例如 `/vs A產品 B產品`，直接對比兩者的規格、優缺點及精準的選購建議。 |
| `/reverse` | 反向思考（挑毛病） | 扮演嚴厲的批評者或紅隊（Red Team），指出目前計畫最容易失敗的盲點。 |
| `/quiz` | 知識測驗（考考我） | 讀完資料後，針對內容隨機出 3 題測試，來驗證我是否真的完全搞懂。 |
| `/analogy` | 尋找精準的比喻 | 幫某個抽象、難懂的概念，找到一個最貼切、好懂的日常生活類比。 |
| `/why` | 探究根本原因（5 Whys） | 模擬連續追問五次為什麼的邏輯，層層剖析並找出某個問題的核心根源。 |
| `/pros` | 列出所有優點、利益 | 全面且具體地列出某個決策、產品或方案所能帶來的全部正面效益。 |
| `/cons` | 列出所有缺點、風險 | 評估某個決策、產品或方案可能帶來的隱藏風險、副作用與負面成本。 |
| `/swot` | 進行 SWOT 分析 | 針對特定的公司、專案、競品或個人，進行強弱危機的全面矩陣評估。 |
| `/ideas` | 腦力激盪發想 | 針對目前的卡關問題，拋棄限制，產出 5-7 個極具創意、跳脫框架的點子。 |
| `/hook` | 設計吸睛爆款標題 | 為指定的文章、影片、產品或活動，設計 5 個讓人忍不住想點擊的標題。 |
| `/story` | 故事化包裝文案 | 將冰冷的產品功能或枯燥的個人經歷，改寫成具有情感共鳴的敘事故事。 |
| `/meme` | 迷因/梗圖構想 | 根據目前主題，發想適合在社群網路上操作、具備擴散力的迷因或梗圖點子。 |
| `/name` | 創意命名構想 | 為新專案、新產品、新功能或新公司，發想 10 個具有記憶點的名稱。 |
| `/script` | 短影音分鏡腳本 | 產出短影音（Reels/TikTok/Shorts）的畫面與旁白音效對照腳本。 |
| `/faq` | 常見問題與防禦答辯 | 自動預測客戶、主管或面試官最可能問的 5 大刁鑽問題，並附上標準答案。 |
| `/schedule` | 時間進度規劃 | 輸入任務與截止日期，自動將專案拆解、排程，轉換為清晰的時程表。 |
| `/budget` | 預算與成本結構預估 | 幫特定的活動、專案或業務模式，粗估可能花費的項目、比例與風險儲備。 |
| `/kpi` | 設定績效評估指標 | 針對特定職務、專案，制定量化且符合 SMART 原則的 KPI 或 OKR 指標。 |
| `/user` | 模擬目標用戶 | 扮演特定族群（User Persona），從他們的真實視角對產品給予辛辣的反饋。 |
| `/interview` | 模擬面試官模式 | 扮演面試官，針對我所應徵的特定產業與職缺，進行一對一的專業問答測試。 |
| `/sop` | 製作標準作業程序 | 將一段工作流程轉換為條理分明、任何人都能照著操作的 SOP 步驟。 |
| `/bug` | 程式碼快速除錯 | 貼上報錯程式碼後，略過客套話，直接指出出錯行數、主因並給出修正代碼。 |
| `/review` | 代碼效能與資安審閱 | 評估程式碼的時間/空間複雜度、資安漏洞及可讀性，並給出重構建議。 |
| `/doc` | 自動補齊註解文件 | 為沒有註解的程式碼或函式，自動加上標準、清晰的 Inline 註解。 |
| `/test` | 編寫單元測試 | 針對提供的 Function 程式碼，自動生成全面且覆蓋率高的 Unit Test 案例。 |
| `/sql` | 轉換為 SQL 語法 | 將白話文的資料撈取與操作需求，精準轉換為結構化查詢語言（SQL）語法。 |
| `/regex` | 生成正規表示式 | 輸入字串篩選規則（如驗證Email、電話），自動生成精確的 Regex 語法。 |
| `/format [格式]` | 強制轉換特定檔案格式 | 例如接續 `/format json`、`/format html`，確保輸出結果格式乾淨無雜質。 |
| `/csv` | 轉換為 CSV 格式 | 將表格或清單轉換為逗號分隔數值（CSV），方便直接匯入 Excel 使用。 |
| `/chart` | 以文字繪製簡易圖表 | 利用文字與符號（如 `█ █ ░ ░`）在對話框內繪製長條圖或趨勢示意圖。 |
| `/recipe` | 清冰箱料理食譜 | 輸入目前手邊現有的剩餘食材，自動調配出符合邏輯、可行的創意食譜。 |
| `/travel` | 旅遊行程規劃 | 給定天數與地點，考慮動線流暢度，生成細緻的每日旅遊行程與注意事項。 |
| `/gift` | 送禮靈感推薦 | 輸入收禮對象、預算、喜好或節日，精準推薦數款不容易踩雷的禮物。 |
| `/fit` | 健身/飲食計畫制定 | 根據身高體重、增肌減脂目標與生活作息，量身打造運動菜單與飲食比例。 |
