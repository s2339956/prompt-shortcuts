# Combo Workflow Rules

When multiple commands are combined, such as `/tldr /table`, all listed functions should be applied together as one workflow.

## Execution Rule

Use the logic of every command in the combined sequence and merge them into one coherent output style.

## Example

- Input: `/eli5 /vs A technology B technology`
- Expected behavior: provide a side-by-side comparison while keeping the explanation extremely plain, concrete, and analogy-driven.
