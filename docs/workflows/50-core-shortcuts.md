# 50 Core Shortcut Commands

## Core Command Definition Table

| Command | Core Function | Execution Rules and Output Requirements |
| :--- | :--- | :--- |
| `/new` | Clear conversation context | Ignore all previous background and settings, and start a completely new, clean topic. |
| `/nofluff` | Get straight to the point | Skip courtesy language, greetings, and unnecessary explanation, and provide only the core answer. |
| `/tldr` | Too long; didn't read | Compress long text, webpages, or uploaded files into the 3 highest-value takeaways. |
| `/table` | Force table output | Replace narrative paragraphs with a Markdown table when organizing data, comparisons, or scattered text. |
| `/action` | Produce action items | Skip background discussion and directly list the concrete follow-up actions from a project or meeting record. |
| `/polish` | Polish writing | Keep the original meaning, fix typos and grammar, and improve fluency and business tone. |
| `/summary` | Structured summary | Organize large amounts of information into clearly titled and segmented summary sections. |
| `/outline` | Generate an outline | Turn unstructured thoughts or materials into a well-structured article or presentation outline. |
| `/keywords` | Extract keywords and tags | Pull out the core keywords and topic hashtags from an article for SEO or tagging use. |
| `/rewrite` | Rewrite with the same meaning | Rephrase awkward text into something smoother and more natural without changing its meaning. |
| `/tone [style]` | Switch tone | Change the response voice based on the requested style, such as humorous or serious. |
| `/reply` | Expand into a business email | Turn a rough idea, such as declining an invitation, into a complete business email draft. |
| `/pitch` | Elevator pitch | Condense a complex project or concept into a short persuasive explanation. |
| `/pr` | Press release format | Convert internal announcements, events, or product updates into a formal press release style. |
| `/slang` | Social media tone | Rewrite stiff copy into an eye-catching style suitable for Threads, Instagram, and similar platforms. |
| `/eli5` | Explain like I'm 5 | Explain complex concepts using daily-life analogies and no technical jargon. |
| `/vs` | Side-by-side comparison | Compare two options directly, including specs, pros and cons, and a precise recommendation. |
| `/reverse` | Reverse thinking | Act as a critical reviewer or red team and identify the most likely failure points in a plan. |
| `/quiz` | Knowledge quiz | After reading material, generate 3 random questions to test whether the content was fully understood. |
| `/analogy` | Find an analogy | Find the most fitting and easy-to-understand everyday analogy for an abstract concept. |
| `/why` | Root-cause analysis | Apply a 5 Whys style breakdown to dig into the real root cause of a problem. |
| `/pros` | List all benefits | Give a complete and concrete list of the benefits of a product, decision, or plan. |
| `/cons` | List all drawbacks | Evaluate possible risks, side effects, and hidden costs of a product, decision, or plan. |
| `/swot` | SWOT analysis | Provide a structured strengths, weaknesses, opportunities, and threats analysis. |
| `/ideas` | Brainstorm ideas | Produce 5 to 7 creative ideas for a stuck problem without over-constraining the thinking. |
| `/hook` | Design catchy headlines | Create 5 click-worthy titles for an article, video, product, or event. |
| `/story` | Turn it into a story | Rewrite dry product features or personal experience into a narrative with emotional resonance. |
| `/meme` | Meme concept ideas | Suggest meme or viral-post concepts suitable for social platform distribution. |
| `/name` | Naming ideas | Generate 10 memorable name ideas for a new project, product, feature, or company. |
| `/script` | Short-video storyboard | Produce a short-form video script with shot descriptions, narration, and sound cues. |
| `/faq` | FAQ and defensive answers | Predict 5 likely hard questions from clients, managers, or interviewers and provide standard answers. |
| `/schedule` | Time and milestone planning | Break tasks down against a deadline and convert them into a clear schedule. |
| `/budget` | Budget and cost estimate | Estimate likely cost categories, ratios, and contingency reserve for an activity, project, or business model. |
| `/kpi` | Set performance metrics | Define SMART KPIs or OKRs for a given role or project. |
| `/user` | Simulate a target user | Role-play a specific user persona and give direct product feedback from that perspective. |
| `/interview` | Interviewer mode | Act as an interviewer and conduct a one-on-one mock interview for a specific role or industry. |
| `/sop` | Create an SOP | Turn a workflow into clear standard operating steps that others can follow directly. |
| `/bug` | Quick code debugging | Skip the small talk and directly identify the error line, root cause, and corrected code. |
| `/review` | Code performance and security review | Evaluate code for time and space complexity, security risk, and readability, then suggest refactors. |
| `/doc` | Auto-document code | Add clear standard inline comments or documentation to undocumented code or functions. |
| `/test` | Write unit tests | Generate thorough unit test cases for the provided function or code block. |
| `/sql` | Convert into SQL | Turn plain-language data retrieval or mutation requests into structured SQL. |
| `/regex` | Generate a regular expression | Build precise regex rules for patterns such as email or phone validation. |
| `/format [type]` | Force a specific output format | Ensure the result is returned cleanly in the requested format, such as JSON or HTML. |
| `/csv` | Convert to CSV | Turn a table or list into comma-separated values for Excel import. |
| `/chart` | Draw a simple text chart | Use characters like `█` and `░` to sketch a bar chart or trend inside the chat. |
| `/recipe` | Fridge-cleanout recipes | Use the available ingredients to produce a realistic creative recipe. |
| `/travel` | Travel itinerary planning | Build a detailed daily itinerary with smooth routing and key travel notes. |
| `/gift` | Gift recommendations | Recommend several low-risk gift options based on recipient, budget, preferences, or occasion. |
| `/fit` | Fitness and diet plan | Build a workout and nutrition plan tailored to body stats, goals, and routine. |
